# 起動と引き継ぎ

カスタム役割を指定できる環境では、その定義を使う。指定できなければ必要な役割の TOML だけを読み、担当指示とモデル・effort を Codex ネイティブの起動引数へ渡す。定義の探索場所はプロジェクトまたはユーザースコープの `.codex/agents/` である。

実装は `relay_implementer`（Luna `max`）または `relay_implementer_std`（Luna `low`）、受け入れテストは `relay_acceptance_writer`（Luna `max`）が既定である。単純なテスト追加は Luna `low`、新規ハーネスや Luna `max` で不足する実装はメイン、または分離が有益なら Sol `high` を候補にする。

モデルを明示する場合は全会話の fork を避け、仕様・対象・制約・参照先に絞った入力を渡す。固定モデルの役割が起動引数より優先する環境では、その役割を選ばず、役割指示と指定値を渡す。モデルや権限を指定できない場合は実際の継承設定を記録し、希望どおりに起動できたと報告しない。

モデルが利用できなければ、原因・途中差分・担当の停止を確認してから、同じ作業境界を保つ利用可能な Codex スレッドへ引き継ぐ。同じ失敗を無条件で再試行せず、Claude へ実装やテスト作成を振り直さない。
